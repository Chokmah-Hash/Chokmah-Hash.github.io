images/

Illustrations du site : cartes de planetes, points d'interet, decors.

Convention proposee :
- images/planetes/<systeme>-<planete>.jpg      : illustration d'une planete
- images/planetes/<systeme>-<planete>-map.jpg  : mappemonde d'une planete
- images/lieux/<planete>-<lieu>.jpg            : illustration d'un point d'interet
