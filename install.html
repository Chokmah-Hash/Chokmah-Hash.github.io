Protocoles Éternels

Safari n’arme aucun bouton : le protocole manuel, trois gestes.

  1. Toucher Partager — le carré barré d’une flèche
  2. Faire défiler, toucher « Sur l’écran d’accueil »
  3. Toucher Ajouter — l’icône est posée, l’application vit

L’icône posée ouvre l’application directement sur la console.
