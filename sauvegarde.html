Sauvegarde du site

Archive ZIP · génération instantanée

Cette page télécharge le site entier — la version en ligne à l'instant présent — dans un fichier ZIP, prête à être conservée ou ouverte hors ligne. Un clic, rien à installer.

Contenu de l'archive

index.html — accueil
regles.html — manuel du joueur (neutre, sans secrets)
fiches.html — application de fiches
mj.html — zone MJ (contenu brouillé, mot de passe non inclus)
sauvegarde.html — cette page
bestiaire.html — bestiaire partagé (nuage)
mon-espace.html — espace joueur (nuage)
galaxie.html — carte de la galaxie (nuage)
LISEZMOI.txt — mode d'emploi

Bon à savoir

Hors ligne : l'archive est un site statique complet — navigation et mise en page incluses. Ouvrez chaque fichier .html dans un navigateur (double-clic) ; seules les données en nuage (fiches partagées, bestiaire, espace joueur) nécessitent internet.

Fiches de personnage : elles vivent dans le stockage local de votre navigateur, pas dans le site — elles ne sont donc pas dans l'archive. Pour les conserver, utilisez les codes d'export de la page Fiches.

Bestiaire : la page bestiaire.html figure dans l'archive, mais les créatures vivent dans la base en nuage — elles se rechargent dès qu'internet revient.

Mon espace : la page mon-espace.html figure dans l'archive, mais comptes, personnages et notes vivent dans la base en nuage — reconnectez-vous pour les retrouver.

Site propre : l'archive est nettoyée automatiquement : aucun script, badge ni marqueur de l'hébergeur n'est inclus — l'archive est un site statique neutre, utilisable telle quelle partout (GitHub Pages compris).

Zone MJ : l'archive contient bien la page mj.html, mais son contenu reste brouillé et le mot de passe n'y figure pas.

Toujours à jour : l'archive est assemblée à partir des pages en ligne au moment du clic — pas d'ancienne copie qui traîne.
